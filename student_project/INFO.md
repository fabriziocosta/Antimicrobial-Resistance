# Testing the Robustness of LLM-Based Scientific Interest Signals in AMR

Antimicrobial resistance (AMR) occurs when bacteria, viruses, fungi, or parasites evolve so that antimicrobial medicines become less effective against them. In practice, this means that infections that were once straightforward to treat can become harder, slower, more expensive, or sometimes impossible to control. AMR is therefore both a clinical and public-health problem: it affects individual treatment decisions, hospital infection control, surveillance programmes, drug development, and global health planning. This project focuses on AMR in the biomedical literature by collecting PubMed evidence for pathogen-antibiotic pairs and modelling how research attention to those pairs changes over time.

The scientific interest of this project is to ask whether literature-derived conclusions about emerging AMR priorities are robust to the choice of large language model used in the pipeline. The LLM is part of the measurement process: it helps decide which abstracts are relevant evidence for a specific pathogen-antibiotic pair, and those decisions feed into yearly publication counts, scientific-interest scores, and rankings of pairs that may deserve closer surveillance. If changing the underlying LLM changes the accepted papers, the estimated trends, or the final priority ranking, then the apparent AMR conclusion may be model-dependent rather than stable. The project will therefore compare outputs across LLMs or settings to quantify agreement, identify fragile cases, and assess whether the main scientific conclusions remain reliable.

## Data collection

The information for this project can be collected from PubMed, a large public database of biomedical research articles maintained by the US National Library of Medicine. PubMed records contain article metadata such as title, journal, publication date, authors, and, when available, the abstract. The project can use the PubMed API, through the NCBI Entrez utilities, to search for articles matching a set of keywords and then retrieve their identifiers, titles, abstracts, and publication years. A practical starting point is to choose a small number of important pathogens, combine each pathogen name with every antibiotic in a predefined antibiotic list, and query PubMed for each pathogen-antibiotic pair. This gives a manageable first dataset of abstracts that can then be screened by different LLMs before aggregating the accepted evidence into yearly counts and scientific-interest measures.

## LLM screening questions

For each PubMed record, the LLM should answer structured questions about one target pathogen-antibiotic pair, not about the abstract in general. The first question is whether the abstract strictly supports an AMR-relevant relation between the target species and the target antibiotic or antibiotic class. This means checking whether resistance, susceptibility, testing, treatment, mechanism, surveillance, or another AMR context is actually attributed to that pair, rather than assuming relevance because the pathogen and antibiotic both appear as keywords. The output can use decision labels such as `strict` when the pair is explicitly linked, `yes` when the pair is supported by a broader study panel or class-level context, `no` when the relation is unsupported or incidental, and `uncertain` only for missing abstracts or technical failures. The LLM should also return a short rationale and evidence phrases from the abstract so disagreements between models can be audited.

The second question is what type of AMR paper the abstract represents, because this allows the scientific-interest signal to be explained at a finer granularity. A useful primary-category scheme is: `SURVEILLANCE` for resistance rates, susceptibility patterns, prevalence, trends, geography, or routine monitoring; `MECHANISMS_OF_RESISTANCE_GENETICS_LAB_STUDIES` for genes, mutations, plasmids, molecular epidemiology, laboratory resistance behaviour, or other biological mechanisms; `CLINICAL_OUTBREAKS_REPORTS` for human infections, patient cohorts, clinical burden, outcomes, case reports, hospital events, or outbreak investigations; `ENVIRONMENTAL_ANIMAL_NON_HUMAN` for animals, food production, wastewater, environmental sampling, One Health transmission, or other non-human reservoirs; `OTHER` for AMR-relevant papers such as diagnostics, stewardship, policy, reviews, modelling, or economic burden that do not fit the main groups; and `NONE` when the target pair is unsupported, ambiguous, or only a weak co-occurrence. Comparing how different LLMs assign both the decision and the paper type will show whether model choice affects only individual abstracts or also changes the interpretation of why a pathogen-antibiotic pair appears scientifically important.

## Scientific interest

At a high level, the project treats the biomedical literature as a signal of where AMR concern is concentrating. After collecting abstracts and using an LLM to decide which papers genuinely support each pathogen-antibiotic pair, the student will count how many relevant papers appear for each pair in each year. Raw counts alone are not enough, because some pathogens and antibiotics are famous and attract many papers for reasons unrelated to a specific resistance signal. The SI model therefore asks a comparative question: is this pair receiving more AMR attention than we would expect given the general visibility of the pathogen and the antibiotic? Pairs with unusually high or rising SI can then be studied as candidates for closer surveillance, while the robustness analysis asks whether those candidates remain the same when the LLM used for screening changes.

Scientific interest (SI) is defined as the amount of AMR publication attention received by a pathogen-antibiotic pair after adjusting for how much general publication attention the pathogen and the antibiotic receive separately. The input table should have one row per `(pathogen, antibiotic, year)` with `count`, the number of LLM-accepted AMR papers for that exact pair and year. Two background tables are also needed: one with `(pathogen, year, count)`, giving the total number of PubMed papers mentioning the pathogen in that year, and one with `(antibiotic, year, count)`, giving the total number of PubMed papers mentioning the antibiotic in that year. After merging these backgrounds onto the pair table, rename them `bg_pathogen_n` and `bg_antibiotic_n`. Rows with missing year, pair count, or background counts should be removed before fitting the SI model.

The SI calculation then works on a transformed count scale so that zero counts are allowed and very large publication counts do not dominate the fit. For every retained row, compute `log_count = log10(1 + count)`, `log_bg_pathogen_n = log10(1 + bg_pathogen_n)`, and `log_bg_antibiotic_n = log10(1 + bg_antibiotic_n)`. Fit one pooled baseline model across all rows, not one model per pair. The response is `log_count`; the predictors are `log_bg_pathogen_n`, `log_bg_antibiotic_n`, one-hot indicators for pathogen identity, and one-hot indicators for antibiotic identity. In formula form, the model is `log_count = alpha + beta_path * log_bg_pathogen_n + beta_ab * log_bg_antibiotic_n + u_pathogen + v_antibiotic + error`, where `u_pathogen` and `v_antibiotic` are the fitted pathogen and antibiotic identity effects. A good default is ridge regression with regularisation strength `alpha=1.0`, which shrinks coefficients and makes the baseline more stable when some pairs are sparse.

For each row, use the fitted model to predict `expected_log_count_global`, the publication count that would be expected for that pair-year given the pathogen background, antibiotic background, and average pathogen/antibiotic effects. Convert this back to the original count scale if needed with `expected_count_global = 10 ** expected_log_count_global - 1`. The scientific-interest score is the residual on the log scale: `SI = log_count - expected_log_count_global`. A positive `SI` means the pair has more accepted AMR publications than expected under the pooled background baseline; a negative `SI` means it has fewer. For robustness analysis, the student can recompute this whole table separately for each LLM, then compare pair-year `count`, `SI`, rank order, and the set of top-priority pairs. The important interpretation is that SI is not a direct measure of biological resistance or clinical danger; it is a standardised literature-attention signal that asks whether a pair is receiving unusually high AMR attention relative to its background visibility.

Because yearly SI can be noisy, especially for rare pathogen-antibiotic pairs with only a few papers, the analysis should work with a smoothed version of the signal when interpreting trends or making future comparisons. The student can fit a simple smoother, such as LOESS, to each pair's yearly SI or to the underlying transformed yearly counts and then derive a smooth SI curve. This reduces the influence of one-off publication spikes, missing abstracts, or individual LLM classification errors, and makes the downstream conclusions more robust. The raw yearly SI values should still be kept for inspection, but the main trend, future prediction, and SI-shift plots should be based on the smoothed signal.

## Future SI vs future SI shift

At an abstract level, this plot is meant to turn the SI modelling output into a decision-oriented map. The aim is not only to forecast which pathogen-antibiotic pairs may have high scientific interest in the future, but also to distinguish pairs that are already high from pairs whose attention is actively rising. This matters because a pair with high future SI but little recent change may represent an established AMR concern, while a pair with a strong positive shift may represent a newer or accelerating signal. The plot therefore helps identify which pairs should be prioritised for interpretation, manual review, or follow-up surveillance analysis.

The final summary plot should compare where each pathogen-antibiotic pair is expected to be in the future with how much its SI is expected to change from the latest observed period. Each point represents one pair. The x-axis is `future_predicted_SI`, the predicted SI at a chosen future year after smoothing and extrapolating the pair's SI trajectory. The y-axis is `future_minus_latest_smoothed_SI = future_predicted_SI - latest_smoothed_SI`, where `latest_smoothed_SI` is the smoothed SI value at the latest available year. This y-axis uses the same definition as the latest-count plot: it measures predicted future SI minus smoothed SI at the latest available year. Each quadrant tells a different story. The upper-right contains pairs with high predicted future SI and a positive shift, suggesting strong and rising attention. The lower-right contains pairs with high predicted future SI but a negative shift, suggesting established concerns whose relative attention may be stabilising or declining. The upper-left contains pairs with lower predicted future SI but positive shift, suggesting early or emerging signals that may not yet be large. The lower-left contains pairs with lower predicted future SI and negative shift, suggesting weak or declining attention, which can still be useful as a contrast group or as evidence that some signals are not robustly increasing.

This plot is the main visual object for the robustness question. The student should generate the same plot separately for each LLM or LLM setting, using the same pathogens, antibiotics, years, smoothing parameters, and plotting thresholds. The goal is to test whether the shape and conclusions of the plot are stable across all quadrants: do the same pairs remain in the same interpretive regions, do the same broad clusters appear, do the most important rankings remain similar, and do any pairs move across the zero-shift or zero-future-SI lines when the LLM changes? Useful quantitative checks include the correlation of `future_predicted_SI` across LLMs, the correlation of `future_minus_latest_smoothed_SI` across LLMs, overlap among top-ranked or quadrant-specific pairs, and a list of pairs whose quadrant changes. If the quadrant structure, visual pattern, and main conclusions remain similar across models, the project can argue that the SI findings are robust; if they change substantially, the student should identify whether instability comes from abstract-level disagreements, category assignment differences, sparse publication counts, or sensitivity of the smoothing and forecasting step.

## Roadmap and milestones

The project is designed for about six weeks of full-time research work, with the first complete version finished by the end of week 4. In week 1, the student should define the scope, select the pathogens and antibiotic list, decide the year window, set up PubMed API access, and write a short protocol for the LLM decision labels, paper categories, and robustness comparisons. The milestone is a reproducible query plan and a small manually inspected pilot dataset.

In week 2, the student should implement the PubMed collection pipeline and retrieve the candidate abstracts for the chosen pathogen-antibiotic grid. This includes saving PubMed identifiers, titles, abstracts, years, pair labels, and basic summary counts by pair and year. The milestone is a clean candidate abstract table ready for LLM screening.

In week 3, the student should implement the LLM screening task and run the abstracts through at least two LLMs or model settings. The output should include the pair-level decision, paper category, rationale, evidence phrases, and any failure or missing-abstract flags. The milestone is a screened dataset for each LLM plus an initial agreement and disagreement summary.

In week 4, the student should complete the first end-to-end analysis: aggregate accepted papers into yearly AMR counts, collect pathogen and antibiotic background counts, calculate SI, smooth the SI trajectories, produce the future SI vs future SI shift plots, assign quadrants, and compute the main robustness metrics. The milestone is a first complete result set showing whether the main plot shape and conclusions are stable.

Weeks 5 and 6 should be reserved for a second round of experiments and writing. The second experimental round can expand the pathogen set, add another LLM, test a different prompt, adjust the smoothing choices, or manually review high-impact disagreement cases. The writing phase should turn the results into a reproducible report explaining the dataset, LLM prompts, SI definition, smoothing method, robustness metrics, stable conclusions, unstable cases, and limitations. The final milestone is a project package containing code, data summaries, plots, and a written answer to the central question: does changing the underlying LLM materially change the AMR scientific-interest conclusions?
